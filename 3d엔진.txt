1. 추천 레이어 구성 방식: '하이브리드 스택' 구조
2D 배경(지적도, 정사영상 등)과 3D 공간을 단일 엔진에서 완벽하게 제어하기 위해 CesiumJS(또는 브이월드 3D v2.0) 단일 엔진을 메인으로 채택하고, 레이어를 아래와 같이 계층화(Stack) 구조로 구성하는 것을 강력히 추천합니다.
• Layer 1 (최하단: 기본 배경): 브이월드 2D WMTS (항공사진 또는 기본지도)
• Layer 2 (중간: 공공/커스텀 2D 레이어): 브이월드 연속지적도, 행정구역 경계 (WMS/WFS 포맷)
• Layer 3 (상단: 3D 레이어): 브이월드 3D 건물 메쉬(3D Tiles) 및 지형 고도(Terrain)
• Layer 4 (최상단: 데이터 레이어): 사용자가 찍는 GCS 기반 웨이포인트(Marker/Entity) 및 이동 경로(Polyline)

const vworldTilesetUrl = 'https://api.vworld.kr?key=' + VWORLD_API_KEY;



// 국토교통부 디지털 트윈 및 3D Tiles 전용 초고속 다이렉트 데이터 채널 주소
const vworldTilesetUrl = 'https://xdworld.vworld.kr/tileset/3d/your_api_key_or_path_here';

// 3D 건물 레이어 직격 바인딩
try {
    vworld3dBldTileset = await Cesium.Cesium3DTileset.fromUrl(vworldTilesetUrl, {
        backFaceCulling: true,
        skipLevelOfDetail: true // 그래픽카드 성능 최적화
    });
    viewer.scene.primitives.add(vworld3dBldTileset);
    vworld3dBldTileset.customType = "facility";
    console.log("🏢 [GCS Layer 3] 브이월드 3D 건물 타일셋 정상 가동!");
} catch (tilesetErr) {
